# BionicApe-Solutions-Inc

## How to set up React for the first time (in the React folder)
* In your command prompt, shell or terminal, type the following command 

        npm install

* Before starting the frontEnd React, let's start the backend server

## On another terminal ( in the main folder), do 

        node app.js


## How to start the React js front end (in the React folder)

* In another terminal, type

        npm start

* The browser should open itself

## If they ask you to run on another port (because it is occupied by the server), say yes. It will run on 3000
